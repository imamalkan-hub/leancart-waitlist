# LeanCart Out-of-Stock Waitlist

[![License: GPL v2](https://img.shields.io/badge/License-GPLv2-blue.svg)](LICENSE.txt)
[![WordPress](https://img.shields.io/badge/WordPress-6.2%2B-21759b.svg)](https://wordpress.org/)
[![WooCommerce](https://img.shields.io/badge/WooCommerce-8%2B-7f54b3.svg)](https://woocommerce.com/)

Collects customer emails for out-of-stock products and notifies them automatically when stock returns.

**Example site:** https://frenectomyguide.com
**Category:** Inventory · **License price:** $24 (Business Bundle: $149)

## Features
* Waitlist form on the product page
* List of signups in the admin panel
* Automatic restock notification
* Captures product, variation, and stock-status changes
* Notified customers can sign up again if the product sells out again

## Installation
1. Download the ZIP from `build/zips/` or download this repository as a ZIP.
2. In WordPress Admin, go to Plugins → Add New → Upload Plugin.
3. Activate the plugin and configure it at **Settings → LeanCart Out-of-Stock Waitlist**.

## Requirements
- WordPress 6.2+, PHP 8.0+
- WooCommerce 8+ (HPOS compatible)
